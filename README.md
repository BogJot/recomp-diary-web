# Рекомп-дневник — веб-версия

Дневник питания и тренировок: калории и БЖУ, вода, шаги, карта мышц, запись тренировок, рецепты, трекер «365 дней».

Открыть: https://bogjot.github.io/recomp-diary-web/

Записи хранятся в браузере на твоём устройстве (и, если включить синхронизацию, в скрытой папке приложения на твоём Google Диске). На сервер сайта ничего не отправляется.

Этот репозиторий собирается автоматически из основного проекта, руками здесь ничего не меняй.
