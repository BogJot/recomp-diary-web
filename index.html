      Карта мышц

      Как считаются цвета

      Для каждой мышцы берётся лучший подход за последние 90 дней: вес и повторы переводятся в расчётный максимум на 1 повтор и сравниваются с телом. Уровни: красный — начальный, оранжевый — новичок, зелёный — средний, розовый — продвинутый, фиолетовый — элита. Пороги для жимов, тяг, бицепса, трицепса и жима ногами взяты из данных Strength Level (около 48 млн подходов мужчин, strengthlevel.com) при весе около 82 кг. Для остальных упражнений пороги подобраны по аналогии, поэтому это ориентир, а не диагноз.

            Сводка в шторке

            —
            Уведомления выключены, сводка не появится.

            Сводка закреплена в шторке: если её смахнуть или очистить уведомления, она сразу вернётся. Убрать её можно только этим переключателем. Цифры обновляются, как только ты что-то записываешь; шаги — когда открываешь приложение, а в фоне примерно раз в полчаса, если телефон это разрешает.

            Оценка еды по фото

            —

            Без настроек фото отправляется в приложение Claude, а его ответ вставляется обратно одной кнопкой. Если есть ключ API Claude, оценка будет прямо здесь. Запросы по ключу платные, их оплачивает владелец ключа.
